# SmartBezierEdge

`SmartBezierEdge` is the default smart edge. It uses diagonal A\* pathfinding and draws a smooth SVG curve through the computed path, the smart equivalent of React Flow's [`BezierEdge`](https://reactflow.dev/api-reference/components/edges/bezier-edge).

```tsx
import { SmartBezierEdge } from "@tisoap/react-flow-smart-edge";

const edgeTypes = { smartBezier: SmartBezierEdge };
```

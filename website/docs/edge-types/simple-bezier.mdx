# SmartSimpleBezierEdge

`SmartSimpleBezierEdge` uses diagonal A\* pathfinding and draws chained cubic bezier segments with handle-position controls, the smart equivalent of React Flow's [`SimpleBezierEdge`](https://reactflow.dev/api-reference/utils/get-simple-bezier-path).

```tsx
import { SmartSimpleBezierEdge } from "@tisoap/react-flow-smart-edge";

const edgeTypes = { smartSimpleBezier: SmartSimpleBezierEdge };
```

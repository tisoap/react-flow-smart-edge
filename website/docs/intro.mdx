# Introduction

Custom edges for [React Flow](https://reactflow.dev) that never intersect with other nodes, using grid-based A\* pathfinding.

![Smart edge example](/img/example.gif)

## Install

With npm:

```bash
npm install @tisoap/react-flow-smart-edge
```

With yarn:

```bash
yarn add @tisoap/react-flow-smart-edge
```

This package requires [React Flow v12+](https://reactflow.dev/learn/troubleshooting/migrate-to-v12) (`@xyflow/react`).

## What you get

- `SmartBezierEdge`: smart equivalent to React Flow's [`BezierEdge`](https://reactflow.dev/api-reference/components/edges/bezier-edge)
- `SmartStraightEdge`: smart equivalent to [`StraightEdge`](https://reactflow.dev/api-reference/components/edges/straight-edge)
- `SmartStepEdge`: smart equivalent to [`StepEdge`](https://reactflow.dev/api-reference/components/edges/step-edge)
- `SmartSmoothStepEdge`: smart equivalent to [`SmoothStepEdge`](https://reactflow.dev/api-reference/components/edges/smooth-step-edge)
- `SmartSimpleBezierEdge`: smart equivalent to [`SimpleBezierEdge`](https://reactflow.dev/api-reference/utils/get-simple-bezier-path)
- `SmartFloatingEdge`: [floating edges example](https://reactflow.dev/examples/edges/floating-edges) with obstacle routing
- `SmartEditableEdge`: [editable edge example](https://reactflow.dev/examples/edges/editable-edge) with pathfinding between segments
- `SmartCheckpointEdge`: fixed waypoints from `edge.data.checkpoints` (library-only; no React Flow example)
- `createSmartEdge`: configure presets at module scope
- `getSmartEdge`: build fully custom smart edges
- `SmartEdgeProvider` and `useSmartEdgePath`: every smart edge routes through this provider, off the main thread on a Web Worker by default
